How is this judged?

Outdated = 10 or more commits behind the upstream default branch, or behind and not bumped for 90 days. Behind = 1 to 9 behind, bumped within 90 days. Current = at the default-branch head. Unpushed = the pinned commit is on no host. Not measured = the commits behind could not be counted (the reason is in the details).

A configuration is judged on its direct pins (its worst one). It is Current only when every direct pin was measured and is current; when some could not be measured and none is worse it reads Current except N not measured. A pin row shows the worst state at or beneath it. Days = since anyone last moved the pin: Fresh under 30 d, Aging 30 to 89 d, Stale 90 d or more.

Rows: {% for g, words, example in LINE_LEGEND %}{{ ui.glyph(g, "fp-glyph") }} {{ words }}: {{ example }}{% if not loop.last %} · {% endif %}{% endfor %}. A configuration is a registered line of its repository; a branch of a pinned repository is written repo:branch.

A frozen silicon configuration is old on purpose: it reads Frozen, says what it would be if live, and is never counted as outdated. ? = a guessed characterisation. [brackets] = not known yet. Pages read stored scans only.
